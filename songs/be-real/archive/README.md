# Archive (not compiled, not registered)

Earlier attempts for "BE REAL": vertical version (`src/lyrics`), landscape prototype (`src/proto`), v2 (`src/v2`), check videos (`src/Composition.tsx`), and their `public/` JSON copies.

They are kept for reference only and are excluded from `tsconfig.json` and eslint. To run one again, add a `<Composition>` in the root `src/Root.tsx`, import it from `../songs/be-real/archive/src/...`, and replace its `staticFile(...)` audio calls with `import song from "../../../assets/real_IBALsS5z.m4a"`.
